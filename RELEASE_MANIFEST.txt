Dependency-lock policy:
- package-lock.json is intentionally not shipped because this environment cannot regenerate a trusted current lockfile from the live npm registry.
- On the first networked install run npm install --include=optional, verify npm audit and npm audit --omit=dev, then commit the generated package-lock.json.
- Render/CI should then use npm ci --include=optional && npm audit --omit=dev.

Operational follow-up after deployment:
- Run npm run diagnose:publishing -- --live --limit=20.
- Reconnect any provider account with readyToPublish=false, effectiveStatus=expired/needs_reconnect/missing_permission, or a failed live provider check.
- Regenerate or re-upload only old local media you intend to republish.
- Enable privileged MFA before granting production administrative access.
