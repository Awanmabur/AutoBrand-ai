# AutoBrand AI — Social Operating System

## Product promise

AutoBrand should feel simple even when the underlying platform is advanced. The main customer loop is:

```text
Create → Store → Approve → Schedule/Publish → Measure → Improve
```

The dashboard, ChatGPT connector, media library, calendar, approvals, social integrations and analytics must reinforce that loop instead of presenting a wall of unrelated tools.

## Main experience

### Dashboard
Shows what needs attention now: connected-channel health, scheduled content, approvals, performance, AI-operator status and Drive readiness.

### Create
One creation entry point for manual copy/media, AutoBrand AI where the plan includes it, or assets generated by the user's connected ChatGPT/Codex.

### Calendar
One publishing timeline across brands and channels, with drafts, approvals, failures and schedules.

### Library
One durable asset library. Storage can be AutoBrand, Google Drive or both.

### Channels
Every supported network has a dedicated workspace showing:
- connected accounts and readiness/blockers;
- recent posts and publish results;
- 30-day impressions/reach/engagement/followers when the provider exposes them;
- publishing success/failure rate;
- recommendations and next actions.

### Analytics
Cross-channel comparison remains separate from channel workspaces so users can answer both “how is Instagram doing?” and “which channel is winning?”

## ChatGPT as an AutoBrand operator

A user can authorize ChatGPT/Codex through OAuth. ChatGPT then operates through the same AutoBrand permissions and publishing pipeline as the dashboard. Typical flows:

1. generate/write creative in ChatGPT;
2. upload the file into AutoBrand / Drive / Both;
3. create or edit a draft;
4. send for approval if required;
5. schedule or publish;
6. inspect provider results and analytics;
7. improve the next post.

ChatGPT never receives social-provider credentials and cannot bypass brand RBAC, plan limits, approval rules or provider readiness.

## Affordability model

Affordability comes from architecture, not from stripping the product down:

- **Publish — US$10/month-access-period:** bring your own creative/AI. ChatGPT connector, Drive, scheduling, approvals and analytics are included; AutoBrand AI generation credits are zero.
- AI tiers charge for AutoBrand-hosted generation capacity, larger scale and advanced automation.
- Google Drive reduces the need to force customers into large platform-storage upgrades.
- The same core workflow exists on every tier so upgrades add capacity/intelligence rather than making the entry plan unusable.

## Superadmin

Superadmin is a platform role, not a customer plan. It must retain:
- wildcard permissions;
- access to every feature;
- unlimited quantitative plan limits;
- unlimited AutoBrand AI credits;
- admin/operations/billing/provider controls;
- no customer upgrade prompts.

## Product rules

1. Advanced capability must not require a complicated interface.
2. Never fabricate social analytics or provider success.
3. One brand/workspace is the tenancy boundary; actor identity remains separate.
4. Every external write is auditable.
5. Provider credentials remain encrypted and server-side.
6. ChatGPT is an operator, not a bypass.
7. User-owned Drive files remain user-owned.
8. New features should attach to the operating loop before earning a new navigation item.
